# Roadmap

## Milestones
- **M1: Baseline Utilities (Current)**: Standalone Python scripts for H.265 compression, batch processing, and audio/video multiplexing.
- **M2: CLI Improvements**: Unified entry point CLI (e.g. `python -m tools ...`), configurable bitrate/preset overrides in `batch.py`, CPU fallback for batch processing when NVENC is unavailable.
